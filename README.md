# manutenção-rede-computador-domestico
Teste de computadors em uma rede domésticas cujo compartilhamento apresentava falha

Teste de computadores em uma rede doméstica vulgo o compartilhamento apresentado falha Foram realizados testes em dois notebooks, incluindo as ferramentas principais do Windows, como Painel de Controle, Configurações de Rede, Adaptadores e Compartilhamento, entre outros. Com isso, foram feitos os seguintes procedimentos:

   1.Configuração do Ip de DHCP automático para endereço de IPV4 Manual;

   2.Teste, utilizando o Prompt de Comando (CMD), e o comando “ipconfig” para ver se a configuração anterior foi feita corretamente;

   3.Alteração, pelo Painel de Controle, das configurações de IP dos computadores 1 e 2;

   4.Criação e teste da pasta e do arquivo compartilhado;

   5.Teste final, excluindo, editando o arquivo dentro da pasta compartilhada, para confirmar seu funcionamento.

Por fim, após os testes, foi percebido que as pastas poderiam ser acessadas normalmente, o notebook 1 poderia “pingar” o IP do notebook 2 normalmente, porém, o notebook 2 não conseguiu “pingar” o IP do 1 normalmente, por estar dando erro de pacote.
